## 新布局

- 左侧固定专家列表，支持搜索、关注、待处理和待回复筛选。
- 右侧固定专家信息，状态、层级、专家标签可展开修改。
- 同页纵向排列：往来信件 → 可信工作台（默认折叠）→ 人工回复（默认展开）→ 操作日志（折叠），不再切换 tab。
- 移除单封邮件查看/处理入口；待处理来信只保留“标记已处理”，发件只显示发送状态。历史正文可原位展开。
- 工作台明确以最新来信为生成依据，保留原始/清洗正文、邮件标签与技术信息；回复草稿切换专家后保留。
- 刘明哲、周子谦为仅发件示例：仍展示在全部列表，可关注，标记“待专家回复”，显示“收 0 · 发 N”和最近发件摘要，不计入待处理。可通过待回复筛选查看。
- 仅发件专家的右侧显示发件记录和等待提示，可人工写跟进邮件；无来信时工作台说明暂无生成依据。
- 本地模拟发送更新会话计数、列表摘要与最近往来排序。
- 原筛选项收纳于筛选条件弹窗：账号、方向、标签、收件人、主题/内容、日期。
- 检查回复、批量发送、自动回复控制保留在全局操作区。

## 预览边界

仅示例数据；所有工作台请求由本地内存适配器响应，不连接正式接口。生成内容、事实和回复框架选项均标明示例。发送仅增加本地会话记录。关注保存在本机 localStorage；其他操作刷新后重置。

批量发送和检查回复展示入口及说明，不执行真实任务。专家资料与附件展示示例。此目录独立于正式前端，未修改或发布正式业务页面。

## V5：专家上传资料区

入口 `http://127.0.0.1:8765/#experts`。先只读核对 Dia 线上页面和 AI 选件弹窗，再复刻专家列表、联系操作栏、材料分类、邮箱别名、阶段历史、资料区。附件文件名/大小来自之前已下载的本地 ZIP 元数据；其余界面字段以用户截图为参考，任务状态为本地演示。没有调用线上分析、发件或资料下载。
