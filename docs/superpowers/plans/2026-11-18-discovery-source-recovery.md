# 深度发现提前结束和核验积压修复

范围为本地 main 的普通深度发现、arXiv 翻页和核验队列。代理调整、线上任务操作及历史批量准入不在本次范围。

- OpenAlex：四次运行在复用登记的资料比较处分别报错四次。只隔离可确定的单人快照差异，记录来源、登记及差异字段。只有留档成功才允许继续消费，原有身份校验、补录所有权、RAW 及准入保护仍然有效。
- Apollo：Free 账号的人物搜索接口返回 403 / API_INACCESSIBLE。应继续处理独立证据足够的专家，依赖不可用接口的专家明确待核验，限制重复调用。历史终态错误使用原重审入口。
- arXiv：线上同条件、同出口复现 start=9900 成功，10000 和 10100 返回 500。需按时间切片分页并接续旧游标；错误不得被吞为来源耗尽。该边界为当前查询实测，不推广为平台通用上限。
- 验收：单人冲突留档成功后下一页可达、留档失败游标保留；Apollo 拒绝后后续独立准入仍执行、未明确者不误准入；arXiv 旧游标、边界、失败重试与时间分片覆盖。使用 JDK 11、隔离 MySQL 和模拟外部 API 验证。
