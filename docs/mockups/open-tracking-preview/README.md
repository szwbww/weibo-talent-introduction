# 首封介绍邮件打开跟踪预览

复用当前系统 index.html 导航与 src/main/resources/static 下的真实样式；独立本地交互预览，数据全为示例，不连接业务 API，不发送邮件。

运行：

```sh
python3 docs/mockups/open-tracking-preview/server.py
```

打开 http://127.0.0.1:18765 。只监听本机；服务器仅允许预览文件与五份系统 CSS，不能访问仓库其他文件。

可体验：总开关（默认关闭、仅当前标签页会话保存）、今日/7天/30天、发件账号、跟踪状态、搜索、分页、详情、首发邮件标签和示例信号更新。

范围：仅首封介绍邮件；所有回复、会议及后续跟进均排除。关闭后停止新跟踪并保留历史。正式后端追踪与配置保存尚未实现。
