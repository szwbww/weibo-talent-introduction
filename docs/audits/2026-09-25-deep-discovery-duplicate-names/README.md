## 典型实例

1. `Daan Van Brusselen`组共10个邮箱。原文Contributor Information逐人列出邮箱，9个属于其他作者：例如`jeroen.deman@uantwerpen.be`对应Jeroen De Man，`melissa.vermeulen@sciensano.be`对应Melissa Vermeulen；只有`daan.vanbrusselen@gza.be`对应Daan本人。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7847293/)
2. `Boon Huan Tan`组共6个邮箱。通讯说明逐人列明：`biedh@nus.edu.sg`是Dean Ho、`tgekyen@dso.org.sg`是Gladys Gek Yen Tan，不能全部归给Boon。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13269110/)
3. `samuelbogdant@gmail.com`线上为Cristian Ichim，原文按独立缩写将其归给Samuel Bogdan Todor，且已有发信记录。[原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13301919/)

重名也可能是正常多邮箱，或不同人恰好同名；没有按名字相同直接判错，也没有按邮箱拼写猜正确姓名。

## 证据方法与质量校验

仅接受作者节点直接邮箱、逐邮箱明确全名、唯一作者缩写标签、独占通讯引用，或Contributor Information中独立的“作者姓名＋邮箱”段落。初步自动结论还要求线上姓名与同篇另一作者对应；其余姓名变体单独复核。10条变体中，2条是中间名省略，另8条原文明确是不同作者。
